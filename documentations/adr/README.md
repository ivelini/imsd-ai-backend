# Архитектурные решения (ADR)

База решений проекта — «почему система устроена так». Полные правила: правило `adr.md` (глобальное), шаблон — `0000-template.md`.

Когда писать: решение, которое иначе переоткроют или переспорят (новый человек, AI-агент, рефакторинг). Не писать: детали реализации, решения без развилки, пересказ механики.
