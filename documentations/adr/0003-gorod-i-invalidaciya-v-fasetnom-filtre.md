# 0003. Город в фасетном фильтре шин и инвалидация кеша индексом ключей

- **Статус:** Accepted
- **Дата:** 2026-08-19
- **Связанные ADR:** 0002 (цены из catalog_prices)

## Контекст

`GET /api/reference/filter/tire` считал фасеты цены и доставки только для города по умолчанию, хотя нижние слои (Action, catalog_prices) уже были готовы к любому городу. Кроме того, `forget()` кеша не попадал в ключи с суффиксом фильтров — инвалидация фактически не работала.

## Решение

Фасеты считаются по `city_id` из запроса (без параметра — город по умолчанию из `config/shop.php`); `city_id` входит в ключ кеша. Инвалидация — через индекс ключей: `remember()` регистрирует ключ в общем индексе, `forget()` удаляет все ключи из индекса.

## Почему (альтернативы)

- **Теги кеша** — недоступны на драйвере `database` (только Redis/Memcached), смена драйвера ради кеша одного эндпоинта не окупается.
- **Удаление по паттерну** — API драйвера не позволяет; глобальный флеш кеша сбил бы и справочники.
- **Точечный `forget()` по известным ключам** — ключи зависят от md5 фильтров, заранее неизвестны.

## Последствия

Проще: публичный каталог стал многогородским, инвалидация работает для всех вариантов фильтров. Сложнее: гонка двух параллельных `remember()` может потерять ключ в индексе — вариант устареет по TTL (приемлемо). Пересмотрим при смене кеш-драйвера на Redis — тогда выгоднее теги.
