# 0008. Админка на Filament вместо admin API + SPA

- **Статус:** Accepted
- **Дата:** 2026-09-09
- **Связанные ADR:** —

## Контекст

Админская часть проекта была построена как JSON admin API (`/api/admin`, sanctum-токены) с отдельным React SPA-фронтом (~6.6k строк TS, не в проде, активная разработка). По FR-спеке сделана ~1/3: впереди CRUD-насыщенные разделы (заказы, клиенты, статьи, автосправочник, роли). Содержать два стека (PHP-слои + React/PrimeReact с дублированием контрактов в zod-типах) для одного внутреннего потребителя дорого; соло-разработка — вся экспертиза в PHP/Laravel.

## Решение

Админка переезжает на Filament-панель внутри backend (`/panel`, session-guard), React-фронт замораживается и удаляется вместе с admin API. Мотив — скорость будущих CRUD-разделов FR. Новые разделы спеки создаются сразу на Filament; существующие переносятся волнами (справочники → товары), при переносе раздела удаляется его API-срез. План миграции — `.claude/plans/filament-migration.md`.

Политика слоёв в Filament: чтение — Eloquent + скоупы моделей; запись доменных сущностей — через существующие Actions/Preconditions (не напрямую Eloquent), чтобы не ломались инварианты (SEO-slug, пересчёт `catalog_prices`, инвалидация кеша Observer'ами). Роли — свои policies по `AdminRoleCode`, spatie не вводится. Уведомления — нативные Filament над существующей таблицей `notifications`.

## Почему (альтернативы)

- **Остаться на React SPA** — впереди ~15+ CRUD-экранов, каждый дороже Filament-ресурса в разы; двойной стек контрактов остаётся навсегда.
- **Гибрид (Filament для новых разделов, React для старых)** — промежуточный этап, принят как способ миграции, но не как конечное состояние: раздвоение UI дороже переноса.
- **spatie/laravel-permission** — роли уже в своих таблицах (`admin_roles`), нужен тонкий каркас, не новый слой прав.
- Цена выбора: уже написанные React-экраны и admin API (контроллеры/Request/Resource/DTO) выпиливаются; Feature-тесты админ-API переписываются в Livewire-тесты.

## Последствия

Проще: один стек и один репозиторий для админки; скорость новых разделов; публичный API каталога не затрагивается. Сложнее: Filament-ресурсы сохраняют данные через Eloquent — политика «запись через Actions» требует дисциплины (хуки форм); реальное время на товарные экраны и импорт (кастомные страницы Livewire).

Пересмотрим при: появлении внешних потребителей admin API (тогда слой API придётся вернуть осознанно) или найме фронтендера с продуктом на React.
