# 0018. Монолит Laravel: Filament-админка и Livewire-сайт, без внешнего API

- **Статус:** Superseded (заменён ADR 0012)
- **Дата:** 2026-09-04 (перенесён из tireslot 2026-09-12, исходный №0005)
- **Связанные ADR:** 0012

## Контекст

Сервис — одна точка шиномонтажа, два интерфейса: публичный сайт записи и админка. Встал вопрос архитектуры: монолит или разделение (микросервисы, SPA + API).

## Решение

Монолит на Laravel: админка — Filament, публичный сайт записи — самостоятельный сайт на Livewire в том же приложении. Внешнего REST API в v1 нет; каналы записи (сайт, админка) используют единые доменные Action/Service.

## Почему (альтернативы)

Микросервисы для одной точки — распределённые транзакции вокруг гонки «закрытие слота vs запись»; пользы нет. SPA + API дали бы внешний контракт, но потребителей нет. Цена: сайт связан с монолитом.

## Последствия

**Superseded:** при переносе в монолит backend выбран вариант «SPA + API» (ADR 0012): Livewire-визард не переносился, публичный канал — `/api/booking` для SPA. Развилка «монолит vs микросервисы» осталась решённой в пользу монолита.
