# Техническое задание — Административная панель

> **Основание:** ТЗ пользовательской части (`tz/user-functional-spec.md`)
> **Доступ:** `/api/admin`, только для авторизованных администраторов

---

## 1. О панели

Административная панель — внутренний инструмент для управления магазином. Доступна только сотрудникам после входа по email и паролю.

**Роли администраторов:**
- **Главный администратор** — полный доступ ко всем разделам
- **Контент-менеджер** — каталог, бренды, SEO-тексты, статьи, справочники
- **Менеджер по заказам** — заказы, клиенты, оплаты, доставка
- **Складской менеджер** — остатки, цены, поставки

---

## 2. Управление каталогом

### 2.1. Товары (шины и диски)

Администратор видит общий список всех товаров с фильтрами: по типу (шины/диски), бренду, статусу, дате добавления, поиск по названию/артикулу/EAN.

**Для каждого товара можно:**
- Редактировать характеристики (зависит от типа товара)
- Загружать и удалять изображения (основное + дополнительные), менять порядок
- Назначать бренд
- Указывать EAN (штрихкод)
- Публиковать / снимать с публикации (товар скрывается из каталога)
- Помечать как «хит продаж» / «новинка»

**Импорт товаров:**
- Возможность загружать XLSX-файлы с товарами
- Система проверяет формат, показывает ошибки (некорректные строки)
- При повторной загрузке — обновление существующих товаров, добавление новых

### 2.2. Бренды

Список брендов с возможностью:
- Добавлять / редактировать / удалять
- Загружать логотип
- Писать описание бренда (для SEO-страницы бренда)
- Указывать тип (шины, диски, оба)

### 2.3. Остатки и цены

**Склады (крупные продавцы):**
- Справочник складов — это крупные продавцы/дистрибьюторы, у которых мы покупаем товар
- Для каждого товара видно: на каком складе, количество, закупочная цена, цена продажи
- Можно вручную корректировать остатки (если склад прислал новый прайс)
- История изменений цен и остатков

**Правила наценки по складам:**
- Для каждого склада можно настроить правила наценки в зависимости от закупочной цены
- Пример правила: «при закупочной цене от 0 до 5 000 рублей — коэффициент 1.2»
- Можно задать несколько диапазонов с разными коэффициентами
- При импорте прайса от склада цена продажи рассчитывается автоматически: закупочная цена × коэффициент наценки
- Рассчитанную цену можно переопределить вручную (если нужно округлить или сделать спецпредложение)

**Поставщики (заводы-производители):**
- Справочник заводов-производителей (Cordiant, Nokian…). Внутренняя информация, клиент не видит.
- Каждый товар привязан к одному поставщику. Один бренд = один поставщик.

### 2.4. Изображения

Администратор может загружать изображения для товаров, обрезать, менять порядок, назначать главное фото. Изображения хранятся локально или в облачном хранилище (S3-совместимом).

## 3. Управление заказами

### 3.1. Список заказов

Общий список всех заказов с фильтрами:
- По статусу (новый, оплачен, в обработке, в доставке, доставлен, отменён, возврат)
- По дате (диапазон)
- По клиенту (имя, телефон, email)
- По сумме
- По способу доставки и оплаты

### 3.2. Работа с заказом

При открытии заказа видно:
- Состав заказа (товары, количество, цена)
- Контактные данные клиента
- Выбранный способ доставки и адрес
- Способ оплаты и статус оплаты
- История изменений статуса (кто и когда менял)

**Действия с заказом:**
- Подтвердить заказ (перевести в «в обработке»)
- Передать в доставку (указать трек-номер, транспортную компанию)
- Отметить как доставленный
- Отменить заказ (с указанием причины)
- Оформить возврат
- Связаться с клиентом (показать телефон/email)

### 3.3. Уведомления о заказах

При создании нового заказа менеджер получает уведомление (в панели). При смене статуса — клиент получает уведомление (email, в перспективе — SMS).

## 4. Управление контентом

### 4.1. SEO-тексты каталога

Управление правилами показа SEO-текстов на страницах каталога (см. ТЗ пользовательской части, раздел 10.2).

**Интерфейс:**
- Список всех правил с фильтром по типу товара
- Создание/редактирование правила:
  - Выбор набора фильтров, для которых показывать текст (тип товара, ширина, профиль, диаметр, сезон, бренд, цена от/до — любое подмножество)
  - Заголовок H1
  - Meta-title (если отличается от H1)
  - Meta-description
  - Основной текст (с форматированием)
  - Приоритет (число)
  - Статус (активно / неактивно)
- Возможность посмотреть, как правило будет выглядеть на странице (превью)

### 4.2. Статьи / блог

CRUD для статей:
- Заголовок, slug (ЧПУ), анонс, полный текст, изображение
- Дата публикации, статус (черновик / опубликована)
- Категория статьи (сезонные советы, подбор, новости)
- SEO-поля: title, description

### 4.3. Справочник терминов

CRUD для терминов (глоссарий):
- Термин, определение
- Категория (шины, диски, общее)

### 4.4. Страницы брендов

Администратор может редактировать описание бренда, которое показывается на странице бренда в каталоге.

## 5. Клиенты

### 5.1. Список клиентов

Таблица всех зарегистрированных пользователей:
- Фильтр: по дате регистрации, наличию заказов
- Поиск: по имени, телефону, email

### 5.2. Карточка клиента

При открытии клиента видно:
- Контактные данные
- Дату регистрации
- Список заказов клиента
- Сохранённые адреса
- Автомобили в гараже
- Общая сумма покупок

---

## 6. Акции

### 6.1. Управление акциями

Список акций + CRUD:
- Название, описание, тип (процент, фиксированная сумма, подарок, спеццена)
- Значение скидки (процент или сумма)
- Даты начала и окончания (акция активна, если текущая дата между ними)
- Привязка товаров: конкретный товар / все товары бренда / весь каталог

Правила применения: если на товар попадает несколько активных акций, применяется та, что привязана к более конкретному объекту: товар → бренд → каталог. Внутри одной категории — с большей скидкой.

---

## 7. Регионы, склады, доставка

### 7.1. Регионы и города

Управление списком регионов и городов (добавление, редактирование).

### 7.2. Наценка по городам

Для каждого города можно настроить правила наценки к цене товара. Наценка — фиксированная сумма в рублях, зависит от базовой цены товара (после наценки склада).

**Пример правил для Москвы:**
- цена товара 0 — 10 000 ₽ → наценка 240 ₽
- цена товара 10 000 — 20 000 ₽ → наценка 120 ₽
- цена товара от 20 000 ₽ → наценка 0 ₽

Если для города правила не заданы — наценка не применяется (0 ₽).

### 7.3. Склады

Управление складами — это крупные продавцы/дистрибьюторы, у которых мы покупаем товар. Поля склада: название (обязательное). Никаких физических адресов — склад не точка выдачи.

### 7.4. Точки выдачи

Управление точками выдачи — это физические адреса, где клиенты забирают товар (самовывоз). Поля: город, адрес, контакты, режим работы.

### 7.5. Стоимость доставки

Управление коэффициентами доставки: настройка стоимости в зависимости от типа товара, цены товара и региона.

### 7.6. График отгрузки

Настройка дней отгрузки по каждому складу: день недели, время отсечки (до какого часа заказ принимается в этот день), количество дней до/после отгрузки.

### 7.7. Сроки доставки по городам

Для каждого города настраивается количество рабочих дней, которое товар едет из Челябинска. Например: Екатеринбург — 2 дня, Москва — 5 дней, Владивосток — 10 дней.

## 8. Администраторы

### 8.1. Управление администраторами

Главный администратор может создавать и редактировать учётные записи сотрудников:
- Имя, email, пароль
- Роль (главный, контент-менеджер, менеджер по заказам, складской)
- Статус (активен / заблокирован)

---

## 9. Автомобили и совместимость

### 9.1. Справочник автомобилей

Управление списком марок, моделей, модификаций автомобилей (CRUD).

### 9.2. Совместимость

Управление таблицей совместимости: какой типоразмер шин/дисков подходит на какую модификацию автомобиля. Возможность:
- Добавлять и удалять связки «модификация → типоразмер»
- Указывать тип совместимости: родной (OEM) / замена / тюнинг
- Импорт совместимости из файла

---

## 10. Дашборд

При входе в админ-панель — сводка ключевых показателей:
- Количество новых заказов сегодня (и за месяц)
- Выручка за сегодня / неделю / месяц
- Топ-10 продаваемых товаров
- Заказы по статусам (сколько в каждом)
- Последние заказы (быстрая ссылка)
- Низкие остатки (товары, которые заканчиваются)
- Активные акции
