# Каталог: ценообразование — полная цена города

> Sources: ADR 0002, 2026-08-13; Проект (architecture.md §9), 2026-08-19
> Raw: [adr-0002-catalog-prices.md](../../raw/project/adr-0002-catalog-prices.md); [architecture.md](../../raw/project/architecture.md); [db-schema.md](../../raw/project/db-schema.md)

## Overview

Финальная цена товара для города предрассчитывается и хранится в `catalog_prices` (пара stock × city) — источник полной цены для фильтрации, сортировки и карточки. Цепочка: закупочная цена → наценка склада → наценка города → акция → округление. Выбор правила наценки — единственная чистая функция `MarkupRuleMatcher` (ADR 0002).

## Цепочка формирования цены

```
purchase_price (прайс склада, импорт)
  → × коэффициент склада (warehouse_markup_rules)  → stocks.price — единая базовая цена
  → + наценка города (city_price_rules)            → базовая цена города
  → − скидка по активной акции                     → цена со скидкой
  → округление до ближайших 100 ₽                  → catalog_prices.price
```

## Правила наценки (matcher)

- **Склад** (`warehouse_markup_rules`): по `warehouse_id`, диапазон `price_from ≤ purchase_price ≤ price_to` → `coefficient`. Пересечения: правило с наименьшим `price_from`, затем наименьшим `price_to`.
- **Город** (`city_price_rules`): по `city_id`, диапазон по `stocks.price` → фиксированный `markup` в рублях. Тот же принцип выбора при пересечениях.
- Оба матчинга — одна чистая функция `MarkupRuleMatcher` (Unit-тесты), которой делегируют все пути: массовый пересчёт, карточка товара, сервисы.

## Акции

Акция активна по датам (`starts_at ≤ now ≤ ends_at`), статусов нет. Привязка полиморфная: конкретный товар (`tire_product`/`wheel_product`) > бренд (`brand`) > весь каталог (`all`); внутри категории — большая скидка. Типы: percent / fixed / gift / special (`PromotionType`).

## Пересчёт catalog_prices

| Событие | Действие |
|---------|----------|
| Изменился `stocks.price` | Пересчитать строки для stock_id по всем городам |
| Изменились `city_price_rules` | Пересчитать строки по затронутым диапазонам |
| Изменилась активная акция | Пересчитать строки затронутых товаров |
| Изменился `delivery_schedules` | Пересчитать сроки stock_id склада по всем городам |
| Изменились `city_delivery_times` | Пересчитать сроки city_id по всем stock_id |
| Импорт прайса | Новые stocks — сразу рассчитать; повторный импорт — только затронутые остатки |

Полный пересчёт — только при изменении географии (импорт точек). Пересчёт через очередь (Job).

## Округление

Математическое до ближайших 100 ₽: 5640 → 5600, 5650 → 5700, 999 → 1000.

## Связанные решения

- Поле `delivery_cost` в админском API остатков удалено: цена уже полная, раздельный возврат задваивал бы сумму (ADR 0002).
- Цена карточки/корзины берётся из `catalog_prices` по городу пользователя (по умолчанию — `config/shop.php default_city`).
