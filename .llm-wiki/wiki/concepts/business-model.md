# Бизнес-модель: цепочка движения товара

> Sources: Проект (architecture.md §5), 2026-08-19
> Raw: [architecture.md](../../raw/project/architecture.md)

## Overview

Компания — малый продавец: не производит и не закупает напрямую с заводов. Товар движется по цепочке из четырёх звеньев, и каждое звено — отдельная сущность с разной видимостью для клиента.

## Цепочка

```
Завод (поставщик) → Крупный продавец (наш склад) → Наша компания → Точка выдачи / Курьер → Клиент
```

## Сущности и видимость

| Сущность | Описание | Видит ли клиент |
|----------|----------|-----------------|
| **Поставщик (supplier)** | Завод-производитель (Cordiant, Nokian…). Внутренний справочник. Один бренд = один поставщик | Нет |
| **Склад (warehouse)** | Крупный продавец/дистрибьютор, у которого покупаем. У каждого склада свои цены и остатки. Не равняется физическому адресу | Нет |
| **Точка выдачи (delivery_point)** | Физическое место, где клиент забирает товар. Нет точки в городе — курьер | Да |
| **Бренд (brand)** | Название модели товара (Winter Drive). Привязан к одному поставщику | Да |

**Наличие товара в городе** = в городе есть хотя бы одна точка выдачи + товар есть на складе, с которым работаем.
