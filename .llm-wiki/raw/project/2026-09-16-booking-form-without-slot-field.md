# Панель: поле «Слот» убрано из формы записи — и с создания

> Source: Проект, сессия 2026-09-16 (правка кода панели по решению пользователя)
> Collected: 2026-09-16
> Published: 2026-09-16

## Что было не так

Поле «Слот» на правке записи выглядело правимым, но сохранение его игнорировало: `UpdateAdminBooking`
берёт слот из записи, а переноса записи на другой слот (ФТ-20) нет. Оператор мог выбрать другой слот,
подставить из него время — и не увидеть переноса.

## Как стало

- С правки поле убрано, **дата слота переехала в заголовок** карточки записи: «Запись 17.09.2026, 11:30,
  Петров Иван, 79001234567» (`EditBooking::getTitle()`; дата — из `$booking->slot?->date`).
- Затем поле убрано **и с создания**: слот в форме не выбирается, он приходит адресом `?slot_id=` со
  страницы слота (кнопка «Добавить запись» в таблице записей слота). Побочный эффект — из формы ушёл
  выпадающий список всех будущих слотов (`Slot::query()` на сотни строк).

## Как сделано

- `BookingForm`: поля `slot_id` нет вообще (не `visibleOn`, а нет поля), мёртвый `fillStartTime()` и импорт
  `Operation` удалены.
- `CreateBooking` (держит `#[Url] public ?int $slot_id`): слот для `CreateAdminBooking` берётся из
  `$this->slot_id`, а не из данных формы.
- Номер слота остаётся в **состоянии формы** (`rawState` в `fillForm()`): на нём держатся варианты времени
  `11:00–11:59` и подстановка начала часа — `BookingForm::slotHour()`/`timeOptions()` читают `$get('slot_id')`
  и не переписывались. Поле не рендерится, но состояние есть.
- Начало часа подставляет страница (`CreateBooking::hourStart()`): прежний `fillStartTime()` срабатывал на
  выборе слота в поле, которого больше нет.
- Создание без слота в адресе отдельно не обрабатывается: вход в создание один — кнопка в карточке слота;
  кнопки «Создать» на листинге записей нет (`ListBookings` без header actions). Прямой заход по адресу даёт
  заголовок «Новая запись» и ответ Action «Слот не найден».

## Грабля на будущее

Состояние без компонента (`data.slot_id` при отсутствующем поле) держится на `rawState` — если Filament
начнёт чистить такое состояние, варианты времени опустеют молча. Ловит тест
`test_time_options_come_from_slot_in_url` (проверяет «11:59» в разметке).
