# Список шин в панели: выбор города — цена, срок и наценка доставки

> Source: План .claude/plans/tire-list-city-price.md + ADR 0011 + код (ListTireProducts, TireProductsTable, DeliveryInfoService)
> Collected: 2026-09-11
> Published: 2026-09-11

## Задача

На `/panel/catalog/tire-products` нужно выбирать город и видеть по нему продукцию: от города зависит срок доставки и наценка на доставку. Город — пункт назначения (везём из Челябинска): наценка — `city_price_rules` (ресурс панели «Наценка на доставку»), срок города — `city_delivery_times.delivery_days`.

## Реализовано

`ListTireProducts` (страница списка):

- `#[Url] public ?int $cityId` — город страницы; состояние живёт в URL (`?cityId=6`), ссылку можно сохранить.
- `mount()`: `cityId ??= City::where('name', config('shop.default_city'))->value('id')` — дефолт «Челябинск». Атрибут `#[Url]` в Livewire 5 применяется раньше `mount()`, поэтому дефолт ставится через `??=`, а не перезаписью.
- `content()`: над таблицей — `Select('cityId')` (поиск, `live()`), ниже `EmbeddedTable`; переопределение штатной схемы List-страницы (`getTabsContentComponent()` + RenderHook'и сохранены).
- `updatedCityId()` → `resetPage()` — смена города возвращает список на первую страницу.
- `table()` передаёт город в конфигурацию таблицы; несуществующий id (устаревшая ссылка) трактуется как отсутствие города.

`TireProductsTable::configure($table, ?City $city = null)`:

- Колонка «Цена в городе (Уфа)»: `12 800,00 ₽ — 5 дн. (наценка 300,00 ₽)`; без города колонки нет, без цены города — плейсхолдер «Нет цены».
- **Цена** — минимум `catalog_prices.price` среди остатков в наличии (`quantity > 0`), как цена листинга каталога (`GetTireList::enrichCityPrices`); tiebreak по id остатка при равных ценах (как в `DeliveryStockPicker`).
- **Наценка** — разница `base_price` и `stocks.price` той же строки снимка (ADR 0002/0009), выводится только если больше нуля: у Челябинска правил нет, наценка не показывается.
- **Срок** — точный расчёт на момент запроса через `DeliveryInfoService::enrichProduct()` (минимум по остаткам товара: дни до ближайшей отгрузки по расписанию склада + дни города), как на карточке товара (FR-1.3.3). Своих правил панель не заводит; диапазон `delivery_min/max` из снимка не используется.
- Запрос листинга: `with('stocks.warehouse.deliverySchedules', 'stocks.catalogPrices' → where city)` — иначе N+1 (цена и срок читаются в каждой строке); `DeliveryInfoService` — один инстанс на рендер (кеш дней и правил города внутри).

## Решения

- Цена и наценка — снимок, срок — расчёт на лету: **ADR 0011**. Альтернативы: считать цену на лету (пятая копия цепочки цены), брать срок из снимка (диапазон устаревает после полуночи), брать наценку из `DeliveryInfoService` (матчится по самому дешёвому остатку и может не сойтись с показанной ценой).
- Наценка выводится вычитанием, а не через matcher: значения согласованы с показанной ценой (одна строка снимка).

## Тесты

`TireProductsTableTest` (+5, всего 7): цена по доступным остаткам и срок оффера; срок после отсечки (`days_after` следующей отгрузки); плейсхолдер без цены города; город из query string; дефолт из конфига + отрисованный селект. Красный прогон: 5 failed / 2 passed → зелёный: 7 passed (22 assertions). Полный сьют 446 passed (1329 assertions), PHPStan без ошибок.

Опции селекта Filament отдаёт в Alpine-атрибуте (`options: JSON.parse(...)`), а не текстом: в тесте проверяется `assertSee('Уфа')` + страховка `entangle('cityId'` (селект должен управлять свойством страницы, иначе выбор города молча ничего не меняет).

## Попутное

- `Stock::catalogPrices()` получил phpdoc `@return HasMany<CatalogPrice, $this>` — без него PHPStan видит `Model` (тот же случай, что `TireProduct::stocks()`).
- Возвращены `recordActions` (Edit/Delete) в таблицу шин: незакоммиченная заготовка их сняла, из-за чего падал `TireResourceTest::test_delete_tire_removes_record` («Action [delete] not found on table»).
- Для проверки в браузере нужен заполненный снимок: при пустых `catalog_prices` колонка показывает «Нет цены» (пересчёт — `PopulateCatalogPrices`, запускается импортом и правкой остатка).
