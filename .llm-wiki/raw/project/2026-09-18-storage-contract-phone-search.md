# Листинг договоров хранения: поиск по телефону клиента

> Source: Правка пользователя в backend (после коммита `8af579a`), изменение кода
> Collected: 2026-09-18
> Published: Unknown

## Что сделано

В листинге договоров хранения (`StorageContractsTable`) колонка «Телефон» стала искомой:
`TextColumn::make('user.phone')->searchable()` — оператор ищет договор по номеру из трубки, а не только
по номеру договора.

## Решения

1. **Ищем по связи штатным механизмом Filament.** Для колонки с путём связи (`user.phone`) вызов
   `->searchable()` превращается в `whereRelation('user', 'users.phone', 'like', …)`
   (`vendor/filament/tables/src/Columns/Concerns/InteractsWithTableQuery.php`), то есть отдельного
   `searchable(query: …)` для телефона не нужно — в отличие от колонки номера, где поиск идёт по
   SQL-выражению (колонки под номер нет).
2. **Телефон ищется как записан** — в каноне «7XXXXXXXXXX»: ввод «8 912…» или «+7 912…» совпадения
   не даст. Осознанно оставлено: нормализации ввода в поиске пока нет.

## Проверки

`tests/Feature/Admin/Booking/StorageContractResourceTest::test_list_search_finds_by_phone` — два договора
с разными телефонами, поиск по одному: виден только его договор (кейс добавлен при записи в историю,
в тест-листе печати его не было).
