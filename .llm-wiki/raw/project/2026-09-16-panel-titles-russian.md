# Панель: русские заголовки страниц — ярлыки ресурсов и подмена строк Filament

> Source: Проект, сессия 2026-09-16 (правка кода + решение по формулировке заголовков)
> Collected: 2026-09-16
> Published: 2026-09-16

## Что изменилось

До правки заголовки страниц собирались Filament из имени класса модели: в 18 ресурсах из 19
жили «Brands», «Создать Brand», «Редактирование Brand» (по-русски были только «Уведомления»,
«Акции», «Импорт», «Каталог шин» и рукописные заголовки страниц записи и слота).
Теперь заголовки русские во всех разделах: «Бренды», «Создание: Бренд», «Изменение: Наценка на доставку».

Три вещи держат русский вид:

- **Ярлыки на ресурсе** — `$modelLabel` (единственное число) и `$pluralModelLabel` (множественное).
  Заголовок листинга берётся из множественного ярлыка (`getTitleCasePluralModelLabel()`),
  страницы создания и правки — из единственного (`CreateRecord::getTitle()`,
  `EditRecord::getTitle()` → `InteractsWithRecord::getRecordTitle()`).
- **Подмена двух строк вендора** — `lang/vendor/filament-panels/ru/resources/pages/create-record.php`
  («Создание: :label») и `edit-record.php` («Изменение: :label»). Русский ярлык в именительном падеже
  не согласуется с глаголом («Создать Бренд», «Редактирование Бренд»); двоеточие снимает согласование
  сразу на всех ресурсах, без кода на каждой странице. Laravel мержит подмену с файлом пакета
  через `array_replace_recursive` (`FileLoader::loadNamespaceOverrides`), поэтому в файле — только
  изменённый ключ, остальные берутся из Filament.
- **Отключение Title Case** — `protected static bool $hasTitleCaseModelLabel = false;` на каждом
  ресурсе. Filament прогоняет ярлык через `Str::ucwords` (`HasLabels::getTitleCaseModelLabel()`),
  а тот капитализирует каждое слово после пробела: «Наценки На Доставку», «Склады Поставщиков»,
  «Расписание Недели». С флагом ярлык выводится ровно как объявлен, поэтому хранится
  с большой буквы первого слова («Наценка на доставку»).

## Грабля: свойство трейта переопределяется только в наследнике

`$hasTitleCaseModelLabel` объявлен в трейтe `HasLabels`, который подключает `Filament\Resources\Resource`.
Объявить его с другим значением в самом классе, подключающем трейт, нельзя (несовместимое свойство —
фатальная ошибка), а в наследнике (`BrandResource extends Resource`) — обычное переопределение
свойства, одна строка. Проверено на PHP 8.5.

## Стража

`tests/Feature/Admin/UiTitlesTest.php` (3 теста): в ярлыках нет латиницы; в заголовке ровно одна
заглавная буква (вернувшийся `ucwords` валит тест); строки «Создание: …» / «Изменение: …» закреплены —
ключи вендора могут переехать при обновлении Filament, и подмена тогда тихо перестанет применяться.

## Попутный краш: заголовок создания записи без слота

В некоммиченной правке `CreateBooking::getTitle()` вызывал `Slot::findOrFail($this->slot_id)`.
Страница создания со страницы слота приходит с `?slot_id=` и работала, а с кнопки «Создать»
на листинге записей id нет — страница падала (10 тестов `BookingResourceTest` были красными).
Закрыто заголовком «Новая запись» при `slot_id === null`.

## Что осталось английским (не трогали)

Заголовки модалок действий и пустого списка — вендорские строки, где ярлык стоит **после** глагола:
«Удалить :label», «Не найдено :model», «Все :label». С русским ярлыком выходит «Удалить Бренд»,
«Не найдено Бренды». Лечится тем же приёмом (подмена ключа в `lang/vendor/filament-actions/ru/…`),
в эту правку не входило.
