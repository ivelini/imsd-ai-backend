## Карта нереализованного (из ФТ)

- ФТ-9: крон чистки просроченных кодов (TTL проверяется, чистки нет).
- ФТ-14: «Моя запись» — отмена клиентом на сайте (SPA-экран; верификатор `booking_code_id` готов).
- ФТ-17: календарь дня с группировкой по слотам (есть список записей).
- ФТ-19: корректировка цены записи оператором (снимок хранится, правка нет).
- ФТ-20: перенос записи (+ следование привязки закрытия слота).
- ФТ-15/16: снятие привязки закрытия при отмене; массовое закрытие слотов дня; создание строки слота при записи на время вне расписания.
- ФТ-18: любое время начала из админки; подстановка госномера/параметров из последней записи клиента.
- ФТ-22: карточка клиента (имя/история/счётчик неявок).
- UI-слой SPA — отдельный план в репо frontend (не входит в перенос backend).
